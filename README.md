# 💬 ChatGenious – AI Messaging Platform

**ChatGenious** è una moderna web app di messaggistica ispirata all'interfaccia di WhatsApp su iPhone, progettata per offrire un'esperienza realistica di chat con un'intelligenza artificiale integrata (Gemini). Include funzionalità di autenticazione sicura, gestione delle conversazioni personalizzate e supporto multilingua.

---

## 🚀 Funzionalità Principali

- 💡 Chat AI con risposte generate da **Gemini**
- 🧑‍💻 Interfaccia utente moderna in stile WhatsApp per iOS
- 🔐 Registrazione e login sicuro tramite **JWT Token**
- 🌍 Supporto multilingua con **i18next**
- 🗂️ Gestione dinamica delle chat (nome, cognome, contesto)
- ♿ UI responsive accessibile da mobile e desktop

---

## 🧰 Tech Stack

### Frontend
- React
- Redux
- Axios
- React Router
- Tailwind CSS
- i18next (internazionalizzazione)

### Backend / AI
- Node.js
- Express
- JWT Authentication
- Gemini API (Google AI)
